The `Blogger` plugin adds blogging functionality to [BakeKit](https://github.com/bakewizard/BakeKit), including posts, categories, and tags.

## Features

- Create and manage blog posts
- Organize posts by category
- Tagging system
- Comments
- SEO-friendly URLs

## Installation

You can install this plugin via the BakeKit Admin Panel by uploading the plugin zip.
